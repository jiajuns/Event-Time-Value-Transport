## Part 3 — 阶段 0 实验：合成时间重参数化对照

### 3.1 ⚠️ 实现前必读：一个会导致假零结果的坑

**核心问题**：如果价值模型的输入是单帧图像，那么 `V(x)` 只是图像的函数。对轨迹做时间重采样**不改变任何一帧的内容**，只改变帧的排列。因此如果你训练一个模型然后在重采样轨迹上评估它，`V` 的每个值都完全不变——你会得到一个漂亮的零结果，并错误地得出"动机不成立"的结论。

**正确的实验设计有两个变体，必须都做，且以变体 A 为主。**

#### 变体 A（训练期畸变）—— 主实验

对每个速度 `c`，用速度为 `c` 的数据**分别训练**一个价值模型 `V_c`，然后把所有 `V_c` 在**同一个固定的评测集**上评估。

- 为什么这是对的：不同机器人执行同一任务产生不同速度的数据，因此学到不同的价值函数。这正是跨本体的直接类比。
- 关键性质：物体轨迹完全相同，事件序列完全相同，**只有训练目标里的时间尺度不同**。
- 配对分析：对**同一张图像** `x`，比较 `V_c(x)` 与 `V_1(x)`。物理状态完全一致，因此"慢就是差"这个解释被排除——这是主结果，不是补充分析。

#### 变体 B（评测期畸变）—— 辅助

用速度 1 的数据训一个模型，在速度 `c` 的轨迹上评估其 **Bellman 一致性**。逐帧 `V` 不变，但 `|r + γV(s') − V(s)|` 会变，因为 `s'` 在轨迹上前进的距离不同。

### 3.2 数据

[已验证] RoboTwin 2.0 数据集有 LeRobot 格式版本：
- `https://huggingface.co/datasets/StarVLA/RoboTwin-Clean`
- `https://huggingface.co/datasets/StarVLA/RoboTwin-Randomized`

**阶段 0 用 Clean 即可。** 选 4–6 个任务，每任务 ~100 条成功轨迹。任务选择标准：多阶段（有明显子步骤）、轨迹长度中等（100–400 步）。记录实际选用的任务名与轨迹数。

**这一步不需要启动仿真器**，纯离线数据即可。如果 GATE 1 卡住，Part 3 仍可独立推进。

### 3.3 时间重采样

实现两种方法，主实验用 (a)，(b) 作为稳健性检查：

**(a) 帧抽样／重复** — 与已有文献可比
```
c > 1（加速）：每 c 帧取 1 帧
c < 1（减速）：每帧重复 1/c 次
```

**(b) 插值重采样** — 排除"合成痕迹"
```
在时间轴上做连续重参数化后对特征插值
```

**扫描范围**：`c ∈ {0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0}`

**必须双向扫。** 只做加速方向会被质疑"是抽帧丢信息导致的"；减速方向不丢信息，如果量纲照样偏移，该解释即被排除。

[参考] TemporalOT（arXiv:2410.21795 附录 A.4）用方法 (a) 报告了 1×/2×/3×/4× 下成功率 94.4 / 91.8 / 77.2 / 43.8。这说明效应存在且量级很大，也说明上述扫描范围合理。**但注意：我们要报告的新东西不是"速度影响性能"，而是"VOC 对此毫无反应"。**

### 3.4 被测模型（5 个）

**不需要跑完整 VLA。** 用一个冻结的视觉骨干（DINOv2 或 SigLIP 均可）提特征，在其上接小 MLP 头。这让整个实验在单卡上几小时可完成。

**关键约束：五个模型必须共享同一批数据、同一个冻结骨干、同等容量的头，只改预测目标。** 否则量纲差异可被归因于容量或表征差异。

| # | 模型 | 预测目标 | 角色 |
|---|---|---|---|
| 1 | 归一化进度 | `[0,1]` 剩余进度 | 控制时间含量 = 0 |
| 2 | 折扣 TD critic | 稀疏终止奖励下的 TD | 控制时间含量 = 部分（藏在 `γ^k` 里） |
| 3 | 剩余步数回归 | 到完成的（负）步数 | 控制时间含量 = 全部（RECAP 式） |
| 4 | 帧序号回归 | `t/T`，**不看图像内容** | 退化对照 |
| 5 | 随机初始化头 | —— | 地板 |

模型 1–3 构成一根**"控制时间含量"轴**，这是本实验的题眼：预测量纲失真沿该轴单调增长，而 VOC 对三者一律给高分。

模型 4 杀伤力最大：它证明 VOC 可以被一个完全不理解任务的模型刷满。一行代码，图上多一条线。

`γ` 取 0.99（并记录；如时间允许，对 `γ ∈ {0.95, 0.99, 0.995}` 做敏感性检查）。

### 3.5 指标

**秩组（预测：平坦）**
- `VOC = Spearman(评测轨迹帧序号, 预测值)`
- Kendall tau（稳健性检查）

**量纲组（预测：随 c 偏移）**
- **配对差异**（主指标）：`mean_x |V_c(x) − V_1(x)|` 与带符号均值，`x` 取共享帧
- `V(s_0)` 均值
- 动态范围 `max V − min V`
- 优势符号一致率（变体 A）
- TD 一致性 `|r + γV(s') − V(s)|`（变体 B）

### 3.6 预期结果表

在跑之前把这张表填进代码注释里，跑完对照。**与预期不符不是失败，是发现**——如实报告。

| 模型 | VOC vs c | 配对 \|V_c − V_1\| vs c |
|---|---|---|
| 1 归一化进度 | 平坦 | 平坦（近零） |
| 2 折扣 TD critic | 平坦 | 增长 |
| 3 剩余步数回归 | 平坦 | **近似线性增长** |
| 4 帧序号回归 | ≈1.0 恒定 | 线性增长 |
| 5 随机头 | ≈0 | 不适用 |

### 3.7 必须控制的混淆项

在报告中逐条回答：

1. **"慢就是差"** —— 由 3.1 的配对分析控制。**确认你做的是同一图像的配对比较，而非轨迹级比较。**
2. **重复帧的分布外效应** —— 方法 (a) 在 `c<1` 时产生连续相同帧。用方法 (b) 复核，报告两者是否一致。
3. **有效训练样本数随 c 变化** —— `c=4` 时数据量只有 1/4。**必须控制：对所有 c 固定训练步数与实际样本数**（重复采样补齐）。这一项如果不控制，整个实验作废。
4. **随机种子** —— 每个 `(模型, c)` 组合至少 3 个种子，报告均值与标准差。VOC 的"平坦"必须是相对于种子间波动而言的平坦。

**主图**：横轴 `c`（对数刻度），双 y 轴——左轴 VOC，右轴配对价值差。五个模型五组曲线。

标题写「指标看不见的失真」，**不要写「速度影响性能」**——后者是已知结果。
